# After v3.0.0

**v3.0.0 is complete** for this tree (`roadmap.md`). Install is the repo scripts
(`INSTALL.md`). Windows NSIS, macOS Developer ID / notarized `.dmg`, and OS
AppData are **cancelled**, not deferred.

Data stays `{launch folder}/data`.

## In-app replace + relaunch

Check For Updates → **Install and relaunch** downloads the GitHub asset for this
OS, exits, and a helper swaps the binary (and `dist/` on the server) then starts
it again. `./data` is not touched.

Needs those files on the release (`.github/workflows/release.yml`
`windows-portable`). If they are missing, the page only offers **Open GitHub
release**.
