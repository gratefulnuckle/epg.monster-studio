# v3 (later)

Not in v2. v2 is playlist curation, EPG, audits, managed output, the local tuner,
Linux **`.deb` + AppImage**, and portable `{launch}/data`. Play uses **mpv** or
**VLC** from Settings paths.

## G-houl Player + IPTV Player

The native GStreamer player (`ghoul.exe`), the IPTV Player nav page, GStreamer
runtime packing, and the NSIS Welcome tick are **v3**.

Until then:

- Do not put G-houl sources in a GitHub push.
- Local checkout may keep a gitignored `./ghoul` folder with the parked tree.
- Studio does not list G-houl as a player and does not show IPTV Player.

## Authenticode / Norton

Unsigned MinGW (a future NSIS setup) can be tagged **Win64.Evo-gen**. A CA
**code-signing** cert (or Azure Artifact Signing) is the lasting fix.

Secrets / env (not used in v2):

| Name | Value |
|------|--------|
| `EPGM_PFX` or `WINDOWS_CERTIFICATE` | path to `.pfx`, or base64 of the PFX |
| `EPGM_PFX_PASSWORD` or `WINDOWS_CERTIFICATE_PASSWORD` | export password |
| `EPGM_CERT_THUMBPRINT` | optional store thumbprint |

`src-tauri/windows/sign.ps1` and `tauri.windows.conf.json` `signCommand` stay in
the tree for that work. Do not turn them on for v2 tester builds.

## Windows NSIS

v3 ships `-setup.exe`. G-houl / GStreamer packing (Welcome tick) is also v3.

## macOS signing / Gatekeeper

v3: Developer ID + notarization. v2 testers use `./studio.sh` (or an
unsigned `.app` if they build one themselves).

## In-app replace + relaunch

Silent update install + relaunch needs an updater signing key. Testers use
`./studio.sh --restart` / `.\studio.ps1 --restart` or a new `.deb` / AppImage.

## OS AppData

v3 may use:

- Windows `%LocalAppData%\epg.monster-studio`
- Linux `$XDG_DATA_HOME/epg.monster-studio` or `~/.local/share/epg.monster-studio`
- macOS `~/Library/Application Support/epg.monster-studio`

v2 always uses `{launch folder}/data` (`EPG_MONSTER_HOME` / repo / exe dir /
AppImage parent).
